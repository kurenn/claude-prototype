Audit 02 — shipped ✓ ▸ tint every neutral, commit to a strategy

Color

The scaffold used to ship flat, untinted grays (--muted: 120 120 120) — the "dead gray" tell both doctrines ban; it now ships tinted OKLCH neutrals. The rule: derive neutrals in OKLCH and tint them toward the palette's hue, commit to one accent, and pick a strategy. Drag the hue below to feel the difference.

  • OKLCH neutrals tinted 0.005–0.015 toward the hue
  • Never #000 / #fff / chroma-0 gray
  • One accent ≤ 10% (restrained)
  • Dark = lighter surfaces, not shadow; desaturate the accent
  • Category-reflex check — not guessable from the domain
Flat · chroma 0 — dead
Tinted · chroma .013 → hue
Tint hue 150°

Same lightness on both rows — the only difference is a whisper of chroma. The tinted ramp reads as chosen; the flat one reads as default. Every surface, border, and muted text derives from it.

Color strategy — commit before you pick

Pick a position on the commitment axis first; it decides how much color the surface carries. Most product UI is restrained; brand/landing pages earn more.

Restrainedtinted neutrals + one accent ≤10%
Committedone color carries 30–60%
Full palette3–4 named roles, each deliberate
Drenchedthe surface IS the color

Audit 03 — shipped ✓ ▸ ease-out, never linear or bounce

Motion & scrolling

Motion is felt, not read — so these are live. The scaffold used to use the browser-default ease curve everywhere; it now ships a small set of ease-out tokens, transform/opacity only, and a reduced-motion fallback. (If your OS has reduce-motion on, these demos correctly sit still.)

  • Never ease / linear / bounce
  • Ease-out quart or expo — real objects decelerate
  • Durations 150 / 250 / 400ms; exits ~75% of entrances
  • transform + opacity only; heights via grid-template-rows
  • Reduced-motion mandatory
linear — robotic
ease — the default, muddy
ease-out-quart ✓
ease-out-expo ✓
bounce — tacky, dated
Ease-out decelerates into place; linear feels mechanical, bounce feels toy-like.

Staggered reveal

One orchestrated page-load stagger beats scattered micro-interactions. Delay = calc(var(--i) * 60ms), capped.

Height, the right way

Animate grid-template-rows: 0fr → 1fr, never height (janky, and it can't animate to auto).

This panel expands by animating grid-template-rows from 0fr to 1fr — smooth, GPU-friendly, and it works with content of unknown height. No JS height measurement.

The tokens to ship

  • --ease-out-quart: cubic-bezier(.25,1,.5,1)
  • --ease-out-expo: cubic-bezier(.16,1,.3,1)
  • --motion-fast: 150ms · --motion: 250ms · --motion-slow: 400ms

Motion personality by tone: technical / minimal → snappy (150ms, quart) · corporate / editorial → calm (250ms, expo) · playful / bold → expressive (staggered reveals). Same tokens, different pacing.

Where this lands: add the ease + duration tokens to styles.css and replace every ease (theme transition, .reveal, .proto-seg) with them; note the pacing in discovery.md Step 4 Motion. Scroll-driven effects (animation-timeline) and View Transitions ship behind a reduced-motion + Firefox fallback.

Audit 04 — shipped ✓ ▸ rhythm, not uniform padding

Spacing & rhythm

Spacing carries structure. One 4pt scale, laid out with gap not margins, and — the part most AI layouts miss — rhythm: tight within a group, generous between groups. Uniform padding everywhere reads as monotone.

  • 4pt scale — 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96
  • gap, not per-element margins
  • Tight in-group (8–12) · generous between (48–96)
  • Whitespace is a design element, not empty

Audit 05 — shipped ✓ ▸ subtle, and dark elevates with surface

Depth & elevation

Depth is a whisper. A subtle, consistent shadow scale in light; in dark, elevation comes from lighter surfaces, not shadow (shadows vanish on dark). Plus a semantic z-index scale so nothing fights with 9999. Flip the ◐ theme to watch the shadow row switch to surface-contrast.

  • Subtle scale — "if you clearly see it, it's too strong"
  • Dark = lighter surface, not shadow
  • Elevation ladder — surface → elevated → elevated-2
  • z-index scale, never 9999

Audit 06 — shipped ✓ ▸ every element, all eight states

A button isn't one thing — it's eight. The scaffold already nails loading / toast / empty / skeleton via ui.js; the gaps are a global :focus-visible ring, an :active press, and a hover-intent guard. Tab through the demos and click the live button.

  • 8 states — default / hover / focus / active / disabled / loading / error / success
  • :focus-visible ring, never outline:none
  • :active press · @media (hover:hover) guard
  • Validate on blur, error below field · undo > confirm
  • 44px touch targets

Audit 07 — shipped ✓ ▸ inline SVG icons, tasteful placeholders

Imagery & icons

The judge caught both marketplace builds using flat color-block "photos" — a real gap for a photo-forward product. Fix: inline SVG icons at one consistent stroke, and placeholder treatments that look considered rather than broken. All zero-dep.

  • Inline SVG from reicon.dev (MIT, copy-HTML), one weight
  • No big rounded icon above every heading
  • Tasteful placeholders, not flat glyphs
  • Initials avatars on tinted circles
  • Lazy-load real images; aspect-ratio box to avoid shift

Icons — one stroke weight, inline

Copy raw HTML/SVG from reicon.dev (2,700+ icons, MIT, multiple weights) — or Lucide / Phosphor — and keep one weight across the set. Don't stack a big rounded icon above every heading; that's the templated tell.
