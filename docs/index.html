Prototypes that refuse to look AI‑generated.

Type /prototype in Claude Code. It asks how the thing should feel, reads real design files, and builds a clickable HTML prototype you can share. No build step.

install, then type /prototype in Claude Code 
git clone https://github.com/kurenn/claude-prototype ~/.claude/skills/prototype
  • Asks before it builds: tone, feel, audience and scope, then one design direction for your yes.
  • Reads 84 real design files and takes their free fonts and design DNA, never the brand.
  • Critiques itself: 37 lint rules and a six-axis self-review on every screen.
  • Ships a control bar to re-skin, comment on and share every screen.
  • Plain HTML, Tailwind CDN and vanilla JS. Nothing to build.
