# Brief: agentic banking with API and CLI first

Feed this verbatim to `/prototype` (choose **Quick** mode), then score the output folder.
No inspiration is named on purpose: this brief tests what the skill reaches for unprompted in
a domain the corpus barely covers (banking), crossed with one it covers well (dev tools).

> Prototype **Keelson**, a bank for AI agents. A company opens one account, then gives each of
> its agents a sub-account with a spend policy (limits, allowed merchants, approval
> thresholds) and its own API key. Developers are the primary users: the API and the CLI are
> first-class, not an afterthought. Tone: technical, calm, trustworthy. Audience: investor
> pitch. Scope: 4 screens — Console (balances + live agent activity), Agents (sub-accounts,
> policies, keys), Developers (API reference + an interactive CLI walkthrough), Ledger
> (every transaction with which agent made it and why; approve or block the held ones).
> Content: realistic placeholder.

Expected from a good run: 4 screens; CLI and API shown as real, copyable commands and
requests (not screenshots of code); agent activity that reads like real agents (vendor
payments, cloud bills, refunds); a held-transaction approval flow with an empty state; key
reveal/rotate with confirmation; no "AI sparkle" clichés.
